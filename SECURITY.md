# Reporting a vulnerability

Report vulnerabilities through GitHub's private vulnerability reporting for the affected repository when available. If the affected repository does not offer private reporting, use the Dastaan organization repository's private report form. [Report a vulnerability privately](https://github.com/DastaanV1/.github/security/advisories/new)

Include the affected repository and revision, reproduction steps, and the impact you observed. Keep credentials, personal data, and exploit details out of public issues and pull requests.
